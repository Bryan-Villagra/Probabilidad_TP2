MÓDULO 4

Probabilidad condicional, total y Bayes

Tres situaciones para distinguir qué fórmula utilizar según la información disponible.

CAJA CON 10 PAPELES

Segundo azul sabiendo que el primero fue rojo

Al principio hay 3 rojos y 7 azules. Como ya salió un rojo y no se repone, quedan 9 papeles: 2 rojos y 7 azules.

P(Azul₂ | Rojo₁) = 7/9 ≈ 0,7778
≈ 77,78 %
Regulador
B175 % 92 % funciona
B225 % 90 % funciona

P(Funciona) = P(B1)·P(F|B1) + P(B2)·P(F|B2)

= 0,75·0,92 + 0,25·0,90

= 0,915 = 91,5 %
AHORA SABEMOS QUE ES DEFECTUOSO

¿Cuál es la probabilidad de que provenga de B2?

P(B2 | D) =
0,25 · 0,10 0,75 · 0,08 + 0,25 · 0,10
= 0,2941 ≈ 29,41 %

Bayes “invierte” la condición: partimos de que el regulador es defectuoso y buscamos de qué proveedor es más probable que haya venido.

Una situación continua y otra discreta. En ambos casos identificamos la variable, su recorrido y las probabilidades solicitadas.

VARIABLE CONTINUA

X = tiempo entre dos llegadas consecutivas a una tienda

Recorrido: X ∈ (0, ∞)

f(x) = ½ e−x/2,   x > 0
1

Constante K

Para que sea una densidad, el área total debe ser 1.

∫₀∞ K e−x/2 dx = 1 ⟹ K = 1/2
2

Función de distribución acumulada

F(x) = 0, si x ≤ 0
F(x) = 1 − e−x/2, si x > 0
3

P(2 < X < 6)

F(6) − F(2) = e−1 − e−3 ≈ 0,3181
≈ 31,81 %
4

P(X ≤ 8)

F(8) = 1 − e−4 ≈ 0,9817
≈ 98,17 %
